## 마스크 편집 관찰
- jpeg-image.png: 가운데 영역이 흰 꽃다발로 편집됨(요청 반영). 바깥은 육안상 구도·인물·배경이 유지되나 수치상 평균 차이 약 20 → 색감·질감이 다시 그려짐. 조건 1(바깥 0px)은 로컬 재합성으로만 보장 가능.

## 결정
- 이미지 전송 형식: **JPEG** 수용 → Task 8 `image.type` 검사·Task 9 `encode(..., 'image/jpeg')` 유지. 요청 본문은 JPEG 약 1.7MB로 4.5MB 이내.
- 응답이 10MB로 4.5MB 초과: `/api/edit`가 응답 본문을 Vercel 함수 응답 제한 안에서 그대로 보낼 수 없음. `output_format`을 jpeg/webp로 바꾸거나 `output_compression`, 더 작은 `MODEL_MAX_PX`, 스트리밍(Fluid compute) 재검토 필요 (사용자 확인 필요, 이번 실측에서는 미측정).
- BiRefNet 모델: **Portrait** (배경 오검출 없음. 부드러운 경계가 필요하면 로컬 blur로 보완).
- 마스크 필드: `mask_image.url` (data URI, PNG 1채널). 입력은 `image_url`에 data URI로 전달 가능, `sync_mode: true`.
