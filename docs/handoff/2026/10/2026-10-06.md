### 핵심 결정
- **fal.ai 제거**(사용자 지시) → 브라우저 분할 선택(사용자 결정). `lib/segment.ts`: transformers.js 4.3.0 + `onnx-community/BiRefNet_lite-ONNX`, WebGPU 어댑터 확인 시 fp16(115MB), 아니면 WASM fp32(224MB). Portrait(fp16 490MB)는 첫 로드가 과해 제외, `SEGMENT_MODEL` 상수로 교체 가능. `FAL_KEY`·`/api/segment` 삭제.
- `/api/edit`의 OpenAI fetch 실패를 502 `{error:'upstream'}`로 매핑, 클라이언트 네트워크·응답 해석 오류는 한국어 안내.
- 40MP 입력 상한은 업로드에만 적용(확장 결과 60MP 채택 가능).
- 최종 리뷰 반영: 크롭 전용 결과도 PNG 재디코딩 검증, CSS 축소 시 브러시·드래그 좌표 보정, 매트 양 끝 스냅(`snapMatte`, ≤8→0·≥247→255), 3:1 초과 프레임 UI 차단, 빈 편집 안내.
- T10 로컬 스모크는 비밀번호·API 비용 문제로 T11로 이관. T2 리뷰는 사용자 결정으로 T11 때 진행.
